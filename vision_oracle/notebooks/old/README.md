# Older notebooks

Kept for reference. They describe earlier models (v1, v2) and earlier test sets, so their numbers do not match the current results in `../C3_v3_measured_results.ipynb`. Several carry a "SUPERSEDED" banner.

Run them from this folder. They look for the project and for the sample images (`opening_screen.png` and similar) in the folder above.

- `pp1/`: the earlier PP1 evidence notebooks, their builder scripts and tests. See `pp1/README.md`.
- `test.ipynb`, `test_inference.ipynb`, `test_model.ipynb`, `train.ipynb`: scratch notebooks.
- The rest are earlier demonstrations and evaluations.
