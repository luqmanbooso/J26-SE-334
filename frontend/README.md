# HEART Framework Frontend (React 18 + Vite)

This directory contains the full interactive web application prototype for the **HEART** (*Human Behavior-Aware Robustness Testing Framework*).

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server (Port 3000)
npm run dev

# 3. Build for production
npm run build
```

## Features Included
- **Figma 1-to-1 Landing Page**: Hero section, module cards, 4-step sequence, deployment cards, FAQ accordions.
- **Analytics Dashboard**: Recharts area & bar charts with rounded corners and glowing stat cards.
- **Biomechanical Touch Heatmaps**: Animated touch dots playback and Fitts's Law interactive sliders.
- **Live ADB Log Stream**: Real-time console stream with interactive chaos triggers (+ Injected Call, + RAM Stress, + 3G Flap).
- **Vision-Semantic Debugger**: Glowing attention heatmap overlay and Defect Metadata panel matching Figma screenshots.
- **Self-Healing Synthesizer**: Interactive Sentence-BERT code remapping animation in Appium Python editor.
- **Zero-SDK App Integration**: Target app configuration & multi-platform snippet generator.
