----------------------------------------------------------------------------------------
7. RULES FOR LABELING NEW OWLEYE SCREENS
----------------------------------------------------------------------------------------
When adding new JSONs to dataset/bugs/:
1. Bounding Boxes: Cover entire widget text width (do NOT clip halfway at x ~ 500).
   Coordinates normalized: [ymin, xmin, ymax, xmax] in range [0, 1000].
2. Taxonomy: Must be one of:
   - component_overlap
   - text_truncation
   - missing_component
   - data_binding_null
   (Never use 'other').
3. Zero Leakage: Always pair bug.X.jpg with normal.X.jpg in the same partition.
4. Incremental Training: Warm-start from results/c3_lora_boosted_recall for ~30 mins.
