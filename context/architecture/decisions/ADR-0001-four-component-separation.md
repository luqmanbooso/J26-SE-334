# ADR-0001: Four-component decoupled subsystem architecture

Decision: Separate HEART framework into four decoupled components (C1 Environmental Perturbation, C2 Human Stress, C3 Vision Oracle, C4 Self-Healing Synthesizer) with clear REST/IPC boundaries. Enables independent research evaluation and modular integration testing via [[IntegrationTestSuite]].
